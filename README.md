# DeepSeek Harness Web 界面中文汉化插件 — 使用方法

## 【这是什么】

一个浏览器端汉化插件包（`dsh-locale-zh`），把 DeepSeek Harness Web 界面中硬编码为英文的部分汉化成简体中文，包括：

- 权限选择器：只读 / 工作区写入 / 完全访问 / 自定义（含描述）
- 斜杠命令描述：`/plan`、`/model`、`/feedback`、`/compact`、`/goal`、`/permission`、`/export`
- AI 推理等级：关闭 / 高 / 最高 / 默认
- 右上角「会话日志」按钮、计划模式、技能标签
- 主对话状态：AI 思考块标题（思考）、工作时提示（深度思考中…）
- 对话中的工具卡片：读取 / 搜索 / 文件匹配 / 终端 / 写入 / 编辑 / 代码 / 工具调用 等
- 轨迹 / 详情面板：工具栏、标签页（摘要/选项/用量/耗时/预览/原始…）、记录类型、轮次与工具调用数、悬浮提示等

它随 `dsh web` 启动自动加载：不需要任何审批，进程重启不会丢失，也不修改任何官方文件（升级 harness 不会受影响）。

## 【文件清单】

| 文件 | 说明 |
| --- | --- |
| `dsh-locale-zh\` | 插件包本体（不要改动） |
| `install.ps1` | 安装脚本 |
| `uninstall.ps1` | 卸载脚本 |
| `README.md` | 详细说明（英文文件名，内容为中文） |

## 【安装前提】

1. 已安装并运行过一次 DeepSeek Harness 的 Web 界面（`dsh web`），使 `%USERPROFILE%\.dsh` 配置目录已经生成；
2. Windows 系统（Win10/11 自带 PowerShell）。

## 【安装步骤】

1. 把压缩包解压到任意目录（例如桌面新建一个文件夹）；
2. 进入解压出的文件夹，右键 `install.ps1` →「使用 PowerShell 运行」；或者在 PowerShell（或 Windows Terminal）中执行：

   ```powershell
   cd 解压目录
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

3. 看到绿色的「安装完成！」即安装成功；
4. 重启 `dsh web`（关闭后重新打开），然后刷新浏览器页面（F5 / Cmd+R）。

安装脚本会自动完成两步：

- a) 把插件包复制到 `%USERPROFILE%\.dsh\node_modules\dsh-locale-zh\`
- b) 在 `%USERPROFILE%\.dsh\cordis.patch.yml` 里追加一行组合配置

> 脚本是幂等的：重复运行不会重复追加，可放心多次执行。

## 【如何确认安装成功】

刷新页面后检查：

- 输入框左侧的权限选择器显示中文（只读 / 工作区写入 / 完全访问）；
- 右上角按钮显示「会话日志」；
- 输入 `/` 后弹出的命令菜单描述均为中文；
- 模型菜单里的推理等级显示：关闭 / 高 / 最高 / 默认；
- 对话中工具卡片标题为中文（读取、搜索、工具调用…）；
- 打开「轨迹」视图：工具栏、标签页、折叠摘要均为中文。

> 浏览器开发者工具控制台可见 `[dsh-locale-zh] 汉化已激活…` 日志。

## 【卸载】

同样方式运行 `uninstall.ps1`，然后重启 `dsh web` 并刷新页面即可恢复英文。

## 【常见问题】

**Q: 运行脚本时提示「禁止运行脚本」？**

A: 使用 `-ExecutionPolicy Bypass` 参数执行，见安装步骤 2。

**Q: 安装后界面仍是英文？**

A:

1. 确认重启了 `dsh web` 并强制刷新（Ctrl+F5）；
2. 确认 `%USERPROFILE%\.dsh\cordis.patch.yml` 中存在 `dsh-locale-zh` 行；
3. `dsh web` 正在运行时修改补丁会自动热重载，稍等几秒再刷新页面。

**Q: 升级 DeepSeek Harness 之后汉化会失效吗？**

A: 通常不会（插件位于用户目录，与官方文件无关）。若个别文字恢复英文，多半是界面构建版本变化，把具体英文反馈给分享者即可补充词条。

**Q: 会影响聊天内容或性能吗？**

A: 不会。翻译采用精确匹配，只替换界面标签，聊天正文不会被改动。

## 【自定义词条（可选）】

用记事本打开 `dsh-locale-zh\lib\client.js`，在 `LABELS` / `TITLES` / `TOOL_TITLES_ZH` / `TOOL_NAMES_ZH` 四个字典里按「英文: 中文」格式增删词条，保存后刷新页面即可生效（无需重新构建）。

## 【兼容性说明】

本插件基于 DeepSeek Harness 0.1.0-rc.6 版验证。大部分汉化在任何构建版本都有效；「轨迹」面板的动态文本（轮次、工具调用数、悬浮提示等）依赖当前构建的界面样式类名，若版本差异较大，该面板部分内容可能保持英文，其余功能不受影响。
